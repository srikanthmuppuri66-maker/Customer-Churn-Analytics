# Customer Churn & Retention Analytics

End-to-end data analytics project using Python (Pandas), SQL Server (SSMS), and Power BI.

## 📊 Dashboard Preview
![Dashboard Screenshot](Screenshot%202026-07-25%20214138.png)

## 🛠️ Tech Stack & Workflow
* **Python (Google Colab):** Dataset cleaning, missing value handling, and feature encoding.
* **SQL (SSMS):** High-risk customer segmentation, contract analysis, and churn metrics calculation.
* **Power BI:** Dynamic KPI cards and visuals showcasing key business retention insights.
